### 振って応援ペンライト めっせんじゃぁ

「振って応援ペンライト めっせんじゃぁ」はライブ配信で推しを応援する、VTuber/YouTuberファンに向けた特別なペンライトです。まさに現実のライブでペンライトを振るように、YouTubeライブ配信でもペンライトを振って推しをチャットで応援できます。

Twitter (X)にて最新情報をチェックしてね！

![](image_Penlight.png)

### IllumiTrack 無線ハンドトラッキングデバイス

IllumiTrackは手・指のモーショントラッキングデバイスです。市販されている同種のデバイスとは異なるセンサー・方式を採用し、お手ごろな価格を実現しました。

専用アプリ「Mocap Assistant Plus」では、IllumiTrackも含めた全身のトラッキングをアプリひとつで実現します。

ご注意： IllumiTrackはVTuber活動などモーショントラッキング向けのデバイスです。VRChatなどVR SNSでの利用には向いていません。

[https://kirisamenanoha.booth.pm/items/6493085](https://kirisamenanoha.booth.pm/items/6493085)

![](image_IllumiTrack.jpg)


### NanoFace フェイストラッカー(無線WEBカメラ)

NanoFaceは、顔の正面に固定して設置できるフェイストラッキング用無線Webカメラです。スマホよりも軽量に、デスクに固定するWebカメラよりも確実なトラッキングを実現します。

専用アプリ「NanoFace」や「Mocap Assistant Plus」とセットで利用します。

[https://kirisamenanoha.booth.pm/items/6135475](https://kirisamenanoha.booth.pm/items/6135475)

  情報の内容: 本システム専用ハードウェアデバイスに内蔵された加速度センサー情報、接続状態、識別情報その他本システムとの連携に必要な情報。  
  利用目的: ペンライトを振る動作の検知、チャット送信トリガーの判定、デバイスの接続管理、表示制御および動作安定化のため。

- **YouTube / Google から取得する情報**  
  情報の内容:  
  a) YouTube アカウントの認証情報（アクセストークン、更新トークン等）  
  b) アカウント識別および表示のためのプロフィール情報（チャンネル名、プロフィール画像 URL その他本システムが表示に利用する範囲の情報）

  a) ログイン状態の維持、YouTube Live チャット送信機能の提供および継続利用のため。  
  b) ログイン中アカウントの識別、一覧表示、ユーザーによるアカウント選択その他 UI 表示のため。  
  なお、認証情報はユーザー端末内に暗号化して保存される場合があります。また、プロフィール情報の一部（例: チャンネル名、プロフィール画像 URL）は、表示およびアカウント識別のためにユーザー端末内に保存される場合があります。

- **本システムの利用に伴い取得または送受信される情報**  
  情報の内容: デバイス識別子、IP アドレス、電池残量、接続先情報、送信設定、コメント設定、アプリ設定、操作状況その他本システムの機能提供に必要な情報。

  利用目的: 次回起動時の再設定負担軽減、アカウント識別、画面表示、継続的な機能提供および操作性向上のため。

- **クリップボードから読み取る情報**  
  情報の内容: ユーザー端末のクリップボード内に一時的に保存されている文字列のうち、本システムが YouTube の動画 URL、ライブ URL、チャンネル URL または各種 ID として解釈可能な情報。  
  利用目的: 対象 URL または ID の自動入力補助のため。  
  なお、クリップボードの内容は、当サークルが外部送信または第三者提供することを目的として取得するものではなく、本システム内の入力補助機能のためにのみ利用します。

- **アップデート確認に伴い送信される情報**  
  情報の内容: アプリの現在のバージョン、通信に付随して送信される IP アドレスその他通常のネットワーク接続に伴う情報。

- **収集しない情報**  
  当サークルは、Google パスワードを取得・保存しません。また、氏名、住所、電話番号等の情報を、当サークルが本システムの通常機能として自動的に取得するものではありません。
